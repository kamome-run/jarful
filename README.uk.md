«У гру я можу зануритися на години, а роботу й хатні справи відкладаю». Jarful перетворює метод
**стікери × прозора банка × термопринтер**, описаний підприємцем із РДУГ Лорі Еро (Laurie Hérault)
([оригінальна стаття](https://www.laurieherault.com/articles/a-thermal-receipt-printer-cured-my-procrastination)),
на застосунок для Android (зокрема Chromebook і ноутбуків Google на ChromeOS/Android) та Windows 11.

> **Jarful** = «повна банка». Зминайте кожен виконаний квиток і дивіться, як наповнюється банка.

## 1. Як це працює

| Метод | У Jarful |
|-----------|-----------|
| Розбивати завдання на **мікрозавдання по 2–5 хвилин**, щоб цикл повторювався часто | Ієрархія завдань у **колонках поруч**; `Tab` миттєво додає підзавдання |
| Один стікер = одне завдання; виконав — **зім'яв і кинув у прозору банку** | Завершення «квитка на сьогодні» запускає **анімацію зминання + шурхіт паперу + вібрацію**, і в банку падає паперова кулька |
| Починати день із легких звичок; **готувати завтрашній день звечора** | **Рутини** за днями тижня створюють квитки на завтра після часу підготовки (типово 21:00) |
| Помітивши прокрастинацію, записати **наступні 3–5 завдань** і почати | `Ctrl+K` **Зосередитися**: по завданню в рядку → одразу квитки → перший запускається |
| Неподільні завдання **ділять за часом** («лише 10 хвилин») | Квитки з таймбоксом ведуть зворотний відлік; наприкінці: «завершити / +5 хв / розбити» |
| Завал (тисячі листів) стає «**усе нове + N старих, щодня**» | **Рутини з квотою** (лічильник +1, завершення при досягненні цілі) |
| **Термопринтер** прибирає тертя | Друк через Bluetooth Classic / Bluetooth LE / COM / TCP за **ESC/POS, TSPL або CPCL**, один квиток — один чек |

## 2. Що знадобиться

**Обов'язково**
- Пристрій на Android (телефон / планшет / Chromebook / ноутбук Google на ChromeOS або Android) або ПК з Windows 11.

**Рекомендовано (щоб відтворити метод повністю)**
- **Термопринтер**: будь-який ESC/POS-сумісний принтер на 58 або 80 мм (Bluetooth Classic, Bluetooth LE або дротова мережа / Wi-Fi). Для етикеток — принтер із підтримкою TSPL або CPCL.
- **Рулони термопаперу** потрібної ширини. Квитки постійно в руках, тому краще **папір без бісфенолу (без BPA/BPS)**.
- **Маркерна дошка та магніти**: надруковані квитки **кріпляться на дошку магнітами**, щоб справи на сьогодні були перед очима. Зняти виконаний квиток і зім'яти його — це і є винагорода. Тримайте напохваті 20–30 маленьких магнітів (10–15 мм).
- **Прозора банка** для зім'ятих квитків. Банки в застосунку достатньо, але справжня підсилює ефект.

## 4. Встановлення

### 4.1 Android (телефон / планшет)

1. Відкрийте [Releases](https://github.com/kamome-run/jarful/releases) у браузері пристрою та завантажте останній `androidApp-debug.apk`.
2. Натисніть на APK у сповіщенні або в застосунку «Файли».
3. Якщо Android попередить про невідомий застосунок, натисніть **Налаштування → Дозволити з цього джерела** й поверніться (одноразовий дозвіл для браузера / «Файлів»).
4. Натисніть **Встановити**, потім **Відкрити**.
5. Під час першого запуску оберіть **Додати приклади**, щоб отримати ранкову рутину, яку потім можна змінити.

> `release-unsigned.apk` призначений для розробників, які підписують і поширюють застосунок самостійно. Зазвичай використовуйте `debug.apk`.

### 4.2 Chromebook / ноутбуки Google на ChromeOS або Android

У ChromeOS є два способи встановити APK не з Google Play.

**Спосіб A: середовище розробки Linux + adb (рекомендовано)**
1. **Налаштування → Додаткові → Для розробників → Середовище розробки Linux → Увімкнути** (уперше триває кілька хвилин).
2. На тому самому екрані ввімкніть **Розробка застосунків Android → Налагодження ADB** і перезавантажтеся.
3. У терміналі Linux встановіть adb і підключіться до пристрою:
   ```bash
   sudo apt update && sudo apt install -y adb
   adb connect 100.115.92.2:5555      # підтвердьте запит на екрані
   adb install ~/Downloads/androidApp-debug.apk
   ```
4. **Jarful** з'явиться в списку застосунків. Вікно можна змінювати в розмірі; за ширини від 840 dp вмикається трипанельний режим.

**Спосіб B: керований Play Store** (пристрої школи / організації): адміністратор може опублікувати APK як приватний застосунок.

Bluetooth-принтер спершу спаруйте в **Налаштування ChromeOS → Bluetooth**, а потім оберіть його в застосунку (працюють і Classic, і LE).

### 4.3 Windows 11

1. Завантажте `Jarful-<версія>.msi` зі сторінки [Releases](https://github.com/kamome-run/jarful/releases).
2. Запустіть інсталятор подвійним клацанням. Якщо з'явиться синє вікно **SmartScreen**, натисніть **Докладніше → Все одно виконати** (інсталятор не підписаний; початковий код відкритий у цьому репозиторії).
3. Підтвердьте теку й натисніть **Install**. Встановлення виконується для поточного користувача, права адміністратора не потрібні.
4. Запустіть **Jarful** із меню «Пуск».
5. Дані зберігаються в `%APPDATA%\Jarful\jarful-data.json` (див. «Розташування» в налаштуваннях).

Видалення: **Параметри → Програми → Інстальовані програми → Jarful**. Файл даних залишається; за потреби видаліть його вручну.

## 5. Перший запуск і розпорядок дня

1. **Налаштуйте рутини** (вкладка «Рутини»): перелічіть згори донизу легкі ранкові звички (зварити каву, відчинити вікно…). Увімкніть потрібні дні тижня; для звичок із лічбою, як-от «розібрати 10 листів», вкажіть число як **квоту**.
2. **Підготовка звечора**: якщо відкрити застосунок після часу «Готувати завтрашній день о» (типово 21:00), з'являться квитки рутин на завтра. Уранці створюються сьогоднішні, якщо їх ще немає.
3. **Розбивайте завдання** (вкладка «Колонки»): створіть велике завдання («Прибирання дому») в лівій колонці, виберіть його й натисніть `Tab` (або «Додати підзавдання»), щоб у наступній колонці з'явилися «Кухня», «Ванна»…, потім дробіть до **2–5 хвилин** («Помити посуд»). Завдання, відкриті понад 3 дні, отримують підказку «розбийте дрібніше».
4. **Створіть квитки на сьогодні**: виберіть завдання й натисніть `T`; для всієї колонки — `Shift+T` (або меню колонки). Вони з'являться картками-чеками на вкладці «Сьогодні».
5. **Надрукуйте й повісьте** (за бажанням): `Ctrl+P` друкує всі квитки на сьогодні; відірвіть їх і **закріпіть на дошці магнітами**.
6. **Зробіть → завершіть**: **Почати** показує час, що минув (для таймбоксу — зворотний відлік). Натисніть **Готово** (або змахніть картку праворуч) — вона зминається й падає в банку зі звуком і вібрацією. Зніміть паперовий квиток, зімніть і киньте у справжню банку.
7. **Спіймали себе на прокрастинації**: `Ctrl+K` (⚡ Зосередитися), запишіть наступні 3–5 завдань по одному в рядку й натисніть **Почати**. Вони одразу стануть квитками, перший запуститься.
8. **Статистика**: цикли за днями (90 днів), серія та виконання рутин.

## 6. Налаштування принтера (докладно)

Вкладка «Налаштування» → **Термопринтер**.

### 6.1 Оберіть спосіб підключення

| Підключення | ОС | Типові принтери |
|---|---|---|
| **Bluetooth Classic (SPP)** | Android / Chromebook | Дворежимні принтери, Bluetooth 2.1–5.x (під час спарювання зазвичай просять PIN) |
| **Bluetooth LE (GATT)** | Android / Chromebook | Кишенькові принтери лише з LE, Bluetooth 4.0–5.x (продаються як «принтер для застосунку») |
| **Serial / COM** | Windows 11 | Принтери Bluetooth Classic через віртуальний COM-порт; перехідники USB-serial |
| **TCP/IP** | Android / Windows | Чекові принтери з дротовою мережею / Wi-Fi (порт 9100) |

Не знаєте, який у вас Bluetooth? Якщо принтер вдається **спарувати** в налаштуваннях Bluetooth системи (запит PIN або підтвердження) — це Classic; якщо спарювання не вдається, а в інструкції написано «підключайтеся із застосунку» — найімовірніше LE. Спробуйте обидва варіанти й залиште той, де проходить **пробний друк**.

### 6.2 Оберіть протокол друку

| Протокол | Призначення |
|---|---|
| **ESC/POS растр (типово)** | Більшість чекових принтерів 58/80 мм. Квиток надсилається зображенням, тому **будь-яка мова друкується правильно незалежно від вбудованих шрифтів** |
| ESC/POS бітове зображення | Старі моделі без растра `GS v 0` |
| ESC/POS текст | Друк вбудованим шрифтом принтера. Доберіть кодування (UTF-8 / Shift_JIS / Big5 / GB18030 / Windows-125x / CP8xx…) під принтер |
| TSPL | Принтери етикеток (висота етикетки та проміжок у мм) |
| CPCL | Принтери етикеток із CPCL |

Ширина паперу — **58 мм (384 точки)** або **80 мм (576 точок)**. У кишенькових принтерів без різака залиште **Cut вимкненим**; 3–5 рядків протягування — добре значення.

### 6.3 Android / Chromebook — Bluetooth Classic

1. Увімкніть принтер; за потреби утримуйте кнопку Bluetooth для режиму спарювання.
2. **Налаштування пристрою → Bluetooth → Додати пристрій**, оберіть принтер і введіть PIN з інструкції (часто `0000` або `1234`).
3. Jarful → Налаштування → Термопринтер → **Bluetooth Classic (SPP)**.
4. Оберіть принтер зі списку спарених пристроїв (🔄 оновлює). На Android 12+ дозвольте доступ до **пристроїв поблизу**.
5. Натисніть **Пробний друк**: за кілька секунд має вийти «Jarful / Test print OK».
6. Якщо друк обривається посередині, збільште кількість рядків протягування або друкуйте квитки по одному (⋮ → Друк).

### 6.4 Android / Chromebook — Bluetooth LE

1. Увімкніть **Bluetooth** (більшості LE-принтерів спарювання не потрібне). На Android 11 і старіших увімкніть також **геолокацію** (потрібна для сканування BLE).
2. Jarful → Налаштування → Термопринтер → **Bluetooth LE (GATT)**.
3. Натисніть 🔄: близько 4 секунд триває сканування, знайдені принтери з'являються в списку. Оберіть свій.
4. **Пробний друк**. Перше підключення може тривати 5–10 секунд.
5. Нічого не друкується: перезапустіть принтер, повністю закрийте фірмовий застосунок (LE-принтер приймає одне підключення) або вимкніть і ввімкніть Bluetooth.

### 6.5 Windows 11 — Bluetooth (віртуальний COM-порт)

1. **Параметри → Bluetooth і пристрої → Додати пристрій → Bluetooth**, спаруйте принтер (PIN з інструкції).
2. **Параметри → Bluetooth і пристрої → Пристрої**, прокрутіть униз і відкрийте **Інші параметри пристроїв і принтерів**.
3. Правий клік по принтеру → **Властивості → Служби**, позначте **Послідовний порт (SPP)** і натисніть **OK**.
4. У тому самому вікні відкрийте **Інші параметри Bluetooth → COM-порти** й запам'ятайте `COMx`, вказаний для принтера як **вихідний**. Якщо його немає: **Додати → Вихідний → обрати принтер → SPP**.
5. Jarful → Налаштування → Термопринтер → **Serial / COM** → оберіть `COMx` → **Пробний друк**.
6. «PORT_OPEN_FAILED» означає, що порт зайнятий іншою програмою (фірмова утиліта) або принтер вимкнений: закрийте її та перезапустіть принтер.

> Версія для Windows не працює з принтерами лише LE. Друкуйте з пристрою Android або використовуйте принтер із TCP.

### 6.6 Мережеві принтери (TCP/IP)

1. Підключіть принтер до мережі й надрукуйте **сторінку самодіагностики** (зазвичай утримуючи кнопку протягування під час увімкнення), щоб дізнатися IP-адресу.
2. Jarful → Налаштування → **TCP/IP** → введіть IP; порт `9100` (типово).
3. **Пробний друк**. Закріпіть IP у роутері (резервування DHCP), щоб він не змінювався.

### 6.7 Порядок «надрукувати й повісити»

- Уранці: вкладка «Сьогодні» → **Надрукувати весь день** (`Ctrl+P`) → відірвати → **закріпити на дошці магнітами** згори донизу.
- Удень: після кожного квитка зніміть його, зімніть і киньте **у прозору банку**. Натискання «Готово» в застосунку додає кульку й у віртуальну банку.
- Увечері: квитки на завтра готуються самі; вранці залишається лише надрукувати.

## 7. Синхронізація Android ⇄ Windows (докладно)

Без хмари й облікових записів. **Пристрої в одній мережі Wi-Fi синхронізуються напряму** (захист PIN-кодом, типовий порт 47831).

### 7.1 Хост (рекомендовано ПК з Windows)

1. Налаштування → **Синхронізація пристроїв** → увімкніть **Зробити цей пристрій хостом**.
2. Запишіть **адреси цього пристрою** (наприклад `192.168.1.20`) і **6-значний PIN**.
3. Якщо брандмауер Windows запитає, чи дозволити Jarful доступ до мережі, дозвольте для **приватних мереж**.
4. Поки застосунок відкритий, він приймає синхронізацію з інших пристроїв («● очікує підключень»).

### 7.2 Клієнт (Android та інші)

1. Налаштування → **Синхронізація пристроїв** → у полі **Підключитися до** введіть **IP-адресу хоста** й **PIN**.
2. Натисніть **Синхронізувати зараз**. «Синхронізовано» підтверджує успіх; кнопка 🔄 на верхній панелі робить те саме.
3. Залиште ввімкненою **автосинхронізацію** — під час запуску та кожні 5 хвилин.

### 7.3 Як це влаштовано та застереження

- Синхронізуються **завдання, квитки, рутини**. Налаштування пристрою (принтер тощо) — ні.
- Якщо обидва пристрої змінили один елемент, **перемагає пізніша зміна**. Видалення теж передаються (пізніше редагування відновлює елемент).
- Трафік — незашифрований HTTP у локальній мережі. Використовуйте в довірених мережах і вимикайте хост у публічному Wi-Fi.
- Три й більше пристроїв працюють, якщо всі підключаються до одного хоста.

## 10. Дані та резервні копії

- Розташування: Android `filesDir/jarful-data.json` (приватна тека застосунку); Windows `%APPDATA%\Jarful\jarful-data.json`.
- **Резервна копія**: Налаштування → Дані → **Експорт JSON (копіювати)** копіює все в буфер обміну; вставте в нотатку.
- **Відновлення**: вставте в **Імпорт JSON**. Поточні дані замінюються (`Ctrl+Z` скасовує один раз).
- Нічого не надсилається з пристрою автоматично; єдиний співрозмовник — налаштований вами хост синхронізації.

## 12. Усунення несправностей

| Симптом | Рішення |
|---|---|
| APK не встановлюється | Дозвольте невідомі застосунки; перевірте, що Android 8.0+ |
| Bluetooth-пристрою немає в списку | Спершу спаруйте в системі (Classic). Для LE натисніть 🔄 ще раз і ввімкніть геолокацію (Android 11 і старіші) |
| Пробний друк не дочекався відповіді | Перевірте живлення, відстань та інші підключені застосунки; для LE закрийте фірмовий застосунок |
| Кракозябри (текстовий режим) | Доберіть кодування під шрифт принтера або перемкніться на **ESC/POS растр** |
| Блідий друк | Глянцевий бік термопаперу має бути повернутий до друкувальної головки |
| У Windows немає COM-порту | Додайте **вихідний** порт, як у 6.5; спаруйте заново |
| Синхронізація: «хост недоступний» | Та сама мережа Wi-Fi? Застосунок хоста відкритий? Брандмауер дозволив? |
| Синхронізація: «неправильний PIN» | Введіть заново PIN, показаний на екрані налаштувань хоста |
| Немає квитків рутин | Перевірте дні тижня та перемикач «Увімкнено»; скористайтеся «Створити заново на сьогодні» |
