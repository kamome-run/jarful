«В игру я могу погрузиться на часы, а работу и домашние дела откладываю». Jarful превращает метод
**стикеры × прозрачная банка × термопринтер**, описанный предпринимателем с СДВГ Лори Эро (Laurie Hérault)
([оригинальная статья](https://www.laurieherault.com/articles/a-thermal-receipt-printer-cured-my-procrastination)),
в приложение для Android (включая Chromebook и ноутбуки Google на ChromeOS/Android) и Windows 11.

> **Jarful** = «полная банка». Сминайте каждый выполненный билет и смотрите, как наполняется банка.

## 1. Как это работает

| Метод | В Jarful |
|-----------|-----------|
| Разбивать задачи на **микрозадачи по 2–5 минут**, чтобы цикл повторялся часто | Иерархия задач в **колонках рядом друг с другом**; `Tab` мгновенно добавляет подзадачу |
| Один стикер = одна задача; выполнил — **смял и бросил в прозрачную банку** | Завершение «билета на сегодня» запускает **анимацию сминания + шорох бумаги + вибрацию**, и в банку падает бумажный шарик |
| Начинать день с лёгких привычек; **готовить завтрашний день с вечера** | **Рутины** по дням недели создают билеты на завтра после времени подготовки (по умолчанию 21:00) |
| Заметив прокрастинацию, записать **следующие 3–5 задач** и начать | `Ctrl+K` **Собраться**: по задаче в строке → сразу билеты → первый запускается |
| Неделимые задачи **делятся по времени** («всего 10 минут») | Билеты с таймбоксом ведут обратный отсчёт; в конце: «завершить / +5 мин / разбить» |
| Завал (тысячи писем) превращается в «**всё новое + N старых, каждый день**» | **Рутины с квотой** (счётчик +1, завершение при достижении цели) |
| **Термопринтер** убирает трение | Печать через Bluetooth Classic / Bluetooth LE / COM / TCP по **ESC/POS, TSPL или CPCL**, один билет — один чек |

## 2. Что понадобится

**Обязательно**
- Устройство на Android (телефон / планшет / Chromebook / ноутбук Google на ChromeOS или Android) или ПК с Windows 11.

**Рекомендуется (чтобы воспроизвести метод полностью)**
- **Термопринтер**: любой ESC/POS-совместимый принтер на 58 или 80 мм (Bluetooth Classic, Bluetooth LE либо проводная сеть / Wi-Fi). Для этикеток — принтер с поддержкой TSPL или CPCL.
- **Рулоны термобумаги** нужной ширины. Билеты постоянно в руках, поэтому лучше **бумага без бисфенола (без BPA/BPS)**.
- **Маркерная доска и магниты**: напечатанные билеты **крепятся на доску магнитами**, чтобы дела на сегодня были перед глазами. Снять выполненный билет и смять его — это и есть награда. Держите под рукой 20–30 маленьких магнитов (10–15 мм).
- **Прозрачная банка** для смятых билетов. Банки в приложении достаточно, но настоящая усиливает эффект.

## 4. Установка

### 4.1 Android (телефон / планшет)

1. Откройте [Releases](https://github.com/kamome-run/jarful/releases) в браузере устройства и скачайте последний `androidApp-debug.apk`.
2. Нажмите на APK в уведомлении или в приложении «Файлы».
3. Если Android предупредит о неизвестном приложении, нажмите **Настройки → Разрешить из этого источника** и вернитесь назад (разовое разрешение для браузера / «Файлов»).
4. Нажмите **Установить**, затем **Открыть**.
5. При первом запуске выберите **Добавить примеры**, чтобы получить утреннюю рутину, которую потом можно изменить.

> `release-unsigned.apk` предназначен для разработчиков, которые подписывают и распространяют приложение сами. Обычно используйте `debug.apk`.

### 4.2 Chromebook / ноутбуки Google на ChromeOS или Android

В ChromeOS есть два способа установить APK не из Google Play.

**Способ A: среда разработки Linux + adb (рекомендуется)**
1. **Настройки → Дополнительные → Для разработчиков → Среда разработки Linux → Включить** (в первый раз занимает несколько минут).
2. На том же экране включите **Разработка приложений Android → Отладка по ADB** и перезагрузитесь.
3. В терминале Linux установите adb и подключитесь к устройству:
   ```bash
   sudo apt update && sudo apt install -y adb
   adb connect 100.115.92.2:5555      # подтвердите запрос на экране
   adb install ~/Downloads/androidApp-debug.apk
   ```
4. **Jarful** появится в списке приложений. Окно можно менять в размере; при ширине от 840 dp включается трёхпанельный режим.

**Способ B: управляемый Play Store** (устройства школы / организации): администратор может опубликовать APK как частное приложение.

Bluetooth-принтер сначала сопрягите в **Настройки ChromeOS → Bluetooth**, затем выберите его в приложении (работают и Classic, и LE).

### 4.3 Windows 11

1. Скачайте `Jarful-<версия>.msi` со страницы [Releases](https://github.com/kamome-run/jarful/releases).
2. Запустите установщик двойным щелчком. Если появится синее окно **SmartScreen**, нажмите **Подробнее → Выполнить в любом случае** (установщик не подписан; исходный код открыт в этом репозитории).
3. Подтвердите папку и нажмите **Install**. Установка выполняется для текущего пользователя, права администратора не нужны.
4. Запустите **Jarful** из меню «Пуск».
5. Данные хранятся в `%APPDATA%\Jarful\jarful-data.json` (см. «Расположение» в настройках).

Удаление: **Параметры → Приложения → Установленные приложения → Jarful**. Файл данных сохраняется; при необходимости удалите его вручную.

## 5. Первый запуск и распорядок дня

1. **Настройте рутины** (вкладка «Рутины»): перечислите сверху вниз лёгкие утренние привычки (сварить кофе, открыть окно…). Включите нужные дни недели; для привычек со счётом, например «разобрать 10 писем», укажите число как **квоту**.
2. **Подготовка с вечера**: если открыть приложение после времени «Готовить завтрашний день в» (по умолчанию 21:00), появятся билеты рутин на завтра. Утром создаются сегодняшние, если их ещё нет.
3. **Разбивайте задачи** (вкладка «Колонки»): создайте крупную задачу («Уборка дома») в левой колонке, выберите её и нажмите `Tab` (или «Добавить подзадачу»), чтобы в следующей колонке появились «Кухня», «Ванная»…, затем дробите до **2–5 минут** («Помыть посуду»). Задачи, открытые больше 3 дней, получают подсказку «разбейте мельче».
4. **Создайте билеты на сегодня**: выберите задачу и нажмите `T`; для всей колонки — `Shift+T` (или меню колонки). Они появятся карточками-чеками на вкладке «Сегодня».
5. **Напечатайте и повесьте** (по желанию): `Ctrl+P` печатает все билеты на сегодня; оторвите их и **закрепите на доске магнитами**.
6. **Сделайте → завершите**: **Старт** показывает прошедшее время (для таймбокса — обратный отсчёт). Нажмите **Готово** (или смахните карточку вправо) — она сминается и падает в банку со звуком и вибрацией. Снимите бумажный билет, сомните и бросьте в настоящую банку.
7. **Поймали себя на прокрастинации**: `Ctrl+K` (⚡ Собраться), запишите следующие 3–5 задач по одной в строке и нажмите **Начать**. Они сразу станут билетами, первый запустится.
8. **Статистика**: циклы по дням (90 дней), серия и выполнение рутин.

## 6. Настройка принтера (подробно)

Вкладка «Настройки» → **Термопринтер**.

### 6.1 Выберите способ подключения

| Подключение | ОС | Типичные принтеры |
|---|---|---|
| **Bluetooth Classic (SPP)** | Android / Chromebook | Двухрежимные принтеры, Bluetooth 2.1–5.x (при сопряжении обычно просят PIN) |
| **Bluetooth LE (GATT)** | Android / Chromebook | Карманные принтеры только с LE, Bluetooth 4.0–5.x (продаются как «принтер для приложения») |
| **Serial / COM** | Windows 11 | Принтеры Bluetooth Classic через виртуальный COM-порт; переходники USB-serial |
| **TCP/IP** | Android / Windows | Чековые принтеры с проводной сетью / Wi-Fi (порт 9100) |

Не знаете, какой у вас Bluetooth? Если принтер удаётся **сопрячь** в настройках Bluetooth системы (запрос PIN или подтверждения) — это Classic; если сопряжение не удаётся и в инструкции написано «подключайтесь из приложения» — скорее всего LE. Попробуйте оба и оставьте тот, где проходит **пробная печать**.

### 6.2 Выберите протокол печати

| Протокол | Назначение |
|---|---|
| **ESC/POS растр (по умолчанию)** | Большинство чековых принтеров 58/80 мм. Билет отправляется картинкой, поэтому **любой язык печатается правильно независимо от встроенных шрифтов** |
| ESC/POS битовое изображение | Старые модели без растра `GS v 0` |
| ESC/POS текст | Печать встроенным шрифтом принтера. Подберите кодировку (UTF-8 / Shift_JIS / Big5 / GB18030 / Windows-125x / CP8xx…) под принтер |
| TSPL | Принтеры этикеток (высота этикетки и зазор в мм) |
| CPCL | Принтеры этикеток с CPCL |
| Cat printer | Карманные принтеры 57 мм без поддержки ESC/POS (семейство GB01 / GT01 / MX06, продаются с приложениями «iPrint» / «Fun Print»). Подключение по BLE |
| Cat printer MXW01 | Новое поколение (семейство MXW01 / X5h; диагностика показывает AE01–AE04). Только BLE |

Ширина бумаги — **58 мм (384 точки)** или **80 мм (576 точек)**. **Плотность печати** (1–5, по умолчанию 4) делает бледную печать темнее. У карманных принтеров без резака оставьте **Cut выключенным**; 3–5 строк протяжки — хорошее значение.

### 6.3 Android / Chromebook — Bluetooth Classic

1. Включите принтер; при необходимости удерживайте кнопку Bluetooth для режима сопряжения.
2. **Настройки устройства → Bluetooth → Добавить устройство**, выберите принтер и введите PIN из инструкции (часто `0000` или `1234`).
3. Jarful → Настройки → Термопринтер → **Bluetooth Classic (SPP)**.
4. Выберите принтер из списка сопряжённых устройств (🔄 обновляет). На Android 12+ разрешите доступ к **устройствам поблизости**.
5. Нажмите **Пробная печать**: через несколько секунд должно выйти «Jarful / Test print OK».
6. Если печать обрывается на середине, увеличьте число строк протяжки или печатайте билеты по одному (⋮ → Печать).

### 6.4 Android / Chromebook — Bluetooth LE

1. Включите **Bluetooth** (большинству LE-принтеров сопряжение не нужно). На Android 11 и старше включите также **геолокацию** (нужна для сканирования BLE).
2. Jarful → Настройки → Термопринтер → **Bluetooth LE (GATT)**.
3. Нажмите 🔄: около 4 секунд идёт сканирование, найденные принтеры появляются в списке. Выберите свой.
4. **Пробная печать**. Первое подключение может занять 5–10 секунд.
5. Ничего не печатается: перезапустите принтер, полностью закройте фирменное приложение (LE-принтер принимает одно подключение) или выключите и включите Bluetooth.

### 6.5 Windows 11 — Bluetooth (виртуальный COM-порт)

1. **Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth**, сопрягите принтер (PIN из инструкции).
2. **Параметры → Bluetooth и устройства → Устройства**, прокрутите вниз и откройте **Другие параметры устройств и принтеров**.
3. Правый клик по принтеру → **Свойства → Службы**, отметьте **Последовательный порт (SPP)** и нажмите **ОК**.
4. В том же окне откройте **Другие параметры Bluetooth → COM-порты** и запомните `COMx`, указанный для принтера как **исходящий**. Если его нет: **Добавить → Исходящий → выбрать принтер → SPP**.
5. Jarful → Настройки → Термопринтер → **Serial / COM** → выберите `COMx` → **Пробная печать**.
6. «PORT_OPEN_FAILED» означает, что порт занят другой программой (фирменная утилита) или принтер выключен: закройте её и перезапустите принтер.

> Версия для Windows не работает с принтерами только LE. Печатайте с устройства Android или используйте принтер с TCP.

### 6.6 Сетевые принтеры (TCP/IP)

1. Подключите принтер к сети и распечатайте **страницу самодиагностики** (обычно удерживая кнопку протяжки при включении), чтобы узнать IP-адрес.
2. Jarful → Настройки → **TCP/IP** → введите IP; порт `9100` (по умолчанию).
3. **Пробная печать**. Закрепите IP в роутере (резервирование DHCP), чтобы он не менялся.

### 6.7 Порядок «напечатать и повесить»

- Утром: вкладка «Сегодня» → **Напечатать весь день** (`Ctrl+P`) → оторвать → **закрепить на доске магнитами** сверху вниз.
- Днём: после каждого билета снимите его, сомните и бросьте **в прозрачную банку**. Нажатие «Готово» в приложении добавляет шарик и в виртуальную банку.
- Вечером: билеты на завтра готовятся сами; утром остаётся только напечатать.

## 7. Синхронизация Android ⇄ Windows (подробно)

Без облака и аккаунтов. **Устройства в одной сети Wi-Fi синхронизируются напрямую** (защита PIN-кодом, порт по умолчанию 47831).

### 7.1 Хост (рекомендуется ПК с Windows)

1. Настройки → **Синхронизация устройств** → включите **Сделать это устройство хостом**.
2. Запишите **адреса этого устройства** (например `192.168.1.20`) и **6-значный PIN**.
3. Если брандмауэр Windows спросит, разрешить ли Jarful доступ к сети, разрешите для **частных сетей**.
4. Пока приложение открыто, оно принимает синхронизацию с других устройств («● ожидает подключений»).

### 7.2 Клиент (Android и другие)

1. Настройки → **Синхронизация устройств** → в поле **Подключиться к** введите **IP-адрес хоста** и **PIN**.
2. Нажмите **Синхронизировать сейчас**. «Синхронизировано» подтверждает успех; кнопка 🔄 на верхней панели делает то же.
3. Оставьте включённой **автосинхронизацию** — при запуске и каждые 5 минут.

### 7.3 Как это устроено и предостережения

- Синхронизируются **задачи, билеты, рутины**. Настройки устройства (принтер и т. п.) — нет.
- Если оба устройства изменили один элемент, **побеждает более позднее изменение**. Удаления тоже передаются (более позднее редактирование восстанавливает элемент).
- Трафик — незашифрованный HTTP внутри локальной сети. Используйте в доверенных сетях и выключайте хост в публичном Wi-Fi.
- Три и более устройств работают, если все подключаются к одному хосту.

## 8. Горячие клавиши

| Клавиша | Действие |
|-----|--------|
| `N` / `Enter` | Новая задача в этой колонке |
| `Tab` / `Shift+Enter` | Добавить подзадачу (разбить) |
| `↑ ↓` | Перемещение по колонке |
| `← →` | Смена колонки |
| `Пробел` | Готово / не готово |
| `T` / `Shift+T` | Билет на сегодня / вся колонка → сегодня |
| `P` / `Shift+P` / `Ctrl+P` | Печать задачи / колонки / всего дня |
| `Ctrl+K` | Собраться |
| `F2` | Переименовать |

| `Alt+↑ ↓` | Изменить порядок |
| `Ctrl+Z` | Отменить |

## 9. Жесты

| Жест | Действие |

## 10. Данные и резервные копии

- Расположение: Android `filesDir/jarful-data.json` (приватная папка приложения); Windows `%APPDATA%\Jarful\jarful-data.json`.
- **Резервная копия**: Настройки → Данные → **Экспорт JSON (копировать)** копирует всё в буфер обмена; вставьте в заметку.
- **Восстановление**: вставьте в **Импорт JSON**. Текущие данные заменяются (`Ctrl+Z` отменяет один раз).
- Ничего не отправляется с устройства автоматически; единственный собеседник — настроенный вами хост синхронизации.

## 12. Устранение неполадок

| Симптом | Решение |
|---|---|
| APK не устанавливается | Разрешите неизвестные приложения; проверьте, что Android 8.0+ |
| Bluetooth-устройства нет в списке | Сначала сопрягите в системе (Classic). Для LE нажмите 🔄 ещё раз и включите геолокацию (Android 11 и старше) |
| Пробная печать не дожидается ответа | Проверьте питание, расстояние и другие подключённые приложения; для LE закройте фирменное приложение |
| Кракозябры (текстовый режим) | Подберите кодировку под шрифт принтера или переключитесь на **ESC/POS растр** |
| Бледная печать | Глянцевая сторона термобумаги должна быть обращена к печатающей головке |
| В Windows нет COM-порта | Добавьте **исходящий** порт, как в 6.5; сопрягите заново |
| Синхронизация: «хост недоступен» | Та же сеть Wi-Fi? Приложение хоста открыто? Брандмауэр разрешил? |
| Синхронизация: «неверный PIN» | Введите заново PIN, показанный на экране настроек хоста |
| Сопрягается, но не подключается (фирменное приложение тоже не работает) | Некоторые **принтеры только с LE перестают подключаться после сопряжения в системе**. Удалите сопряжение в настройках Bluetooth → перезапустите принтер → выберите в Jarful **Bluetooth LE** → 🔄 → Пробная печать. Полностью закройте фирменное приложение. Если не помогло, вставьте отчёт **Диагностика подключения** в issue |
| Не подключается на OPPO / Xiaomi / Huawei | Разрешите «Устройства поблизости» и «Геолокацию», включите геолокацию, отключите оптимизацию батареи для Jarful. При сбое Classic автоматически пробуется LE, и рабочий способ сохраняется |
| Нет билетов рутин | Проверьте дни недели и переключатель «Включена»; используйте «Пересоздать на сегодня» |

## 13. Сборка из исходников

```bash
# модульные тесты (домен, кодирование печати, синхронизация, скриншоты)

./gradlew :androidApp:assembleDebug
# установщик Windows (запускать в Windows)
./gradlew :desktopApp:packageMsi
# запуск настольной версии
./gradlew :desktopApp:run
```

спецификация — [docs/SPEC.md](docs/SPEC.md), конспект статей — [docs/SOURCES.md](docs/SOURCES.md) (на японском).
